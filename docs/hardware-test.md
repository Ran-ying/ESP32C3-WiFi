# 实机验收（待人工执行）

不将未执行的步骤记为 PASS。请只使用自己的 WPA2-Personal + CCMP 路由器。关闭自动信道与 WPA3 过渡模式，2.4 GHz 固定 CH1。

1. 记录串口中的设备热点密码，iPhone 加入 ESP32C3-Auditor，Safari 打开 http://192.168.4.1 。如提示无互联网，保持加入该网络。
2. 确认显示 AP、IP、实际 CH1。勾选授权，点击被动扫描；按 BSSID 区分同名 SSID。
3. 选择自己的测试 BSSID。先看到切换通知，再发生断线；重新加入同一个 ESP32 热点，打开相同地址。实际信道应与目标一致，MCU 不重启。
4. 将测试路由器改为 CH6，再扫描、选择、重连；随后重复 CH11，最后重复 CH1。记录实际信道、重连耗时、异常及启动计数。不能只根据 UI 的目标信道判定成功。
5. 扫描期间监听必须暂停。路由器自动换信道后需要重新选择。ESP32 的 AP 信标和手机网页流量仍存在；“被动”指不干扰目标网络、STA 不连接目标。
6. M2/M3 步骤将在实现后补充；使用另一台自己控制的终端正常加入测试路由器，手机可继续留在 ESP32 热点。

设备不会发起 deauth/disassoc 或强制任何终端重连。
